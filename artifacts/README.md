# Distributed research model artifacts

Original near-target and experimental distal model weights are included with explicit maintainer authorization. See [model installation and training](../docs/MODELS.md) and [hashes / provenance](MODEL_MANIFEST.json).
Source DICOMs and case caches are not included. Publication examples contain only neutral target-level metrics and dose/contour renderings, without source CT.
Pickle/joblib files can execute code: never load untrusted model files.
